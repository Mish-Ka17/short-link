## О проекте Short-link

<p>Проект реализует сервис по созданию коротких ссылок, отслеживанию переходов (кликов) по ним и управлению ссылками через личный кабинет зарегистрированного пользователя. </p>
<p>Проект реализован на Laravel с использованием админ-панели Filamentphp</p>
<P>В проекте предусмотрена регистрация пользователя на основе введенных эл.почты и пароля.</P>
<p>Зарегистрированный пользователь создает короткие ссылки, видит список созданных ссылок, имеет возможность корректировать их и удалять, а также просматривать статистику по каждой ссылке (IP-адрес пользователя,
дата и время перехода).</p> По клику на короткой ссылке происходит ее копирование в буфер обмена для последующего использования в строке запроса url браузера.</p>
